# Public repository disclosure and provenance policy — v1.0
Established: 2026-11-03. This is a public-facing policy, not a certification of past releases.

This repository is a public showcase. Do not place confidential client/owner requirements, internal change-control records, proprietary architecture, credentials, contracts, personal data, unreleased features or private Project Documents here. Those belong only in authorized private repositories or secure storage.

Before every release, review the exact commit and assets for confidential information, licenses, third-party logos/images, personal data, secrets and unsupported claims. Identify simulated data and results; never imply real client work, live inventory, production readiness, approvals or verified tests without evidence. Record substantive changes in Git commit history and maintain detailed version, approval, testing and disclosure records in the corresponding private project repository when one exists.

Public Git history may retain prior disclosures even after a file is deleted; removing a file from the current branch is not a guarantee of erasure. Seek qualified legal advice for IP registrations, confidentiality, licensing and infringement.
