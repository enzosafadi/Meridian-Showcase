## Required acceptance evidence per stage

1. **Concept:** Business use case, target buyers, constraints and value hypothesis.
2. **Requirements:** Versioned owner-approved scope and testable acceptance criteria.
3. **Prototype:** Reproducible demo, safe test data and clearly documented limitations.
4. **Integration / data:** Validated data contracts and failure handling.
5. **Quality / security:** Passing CI, browser/functional tests, threat model, IP review.
6. **Production:** Approved deployment, access controls, monitoring, incident response, rollback.
7. **Buyer outreach:** Approved sales targets, outreach evidence, client demonstration.
8. **Sale:** Executed contract, agreed acceptance and recorded sale.
